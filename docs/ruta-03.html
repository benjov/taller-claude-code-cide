Ruta 03 · Datos

📊 Notebook reproducible con datos del Banco Mundial, 3 gráficas, un modelo simple y un reporte HTML.

Te llevas

Notebook reproducible con datos del Banco Mundial, 3 gráficas, un modelo simple y un reporte HTML.

Ideal para

Quien trabaja con datos cuantitativos (Python, R o Stata).

Tiempo

≈35 min en 6 niveles

Programación

Python (o R / Stata)

📥 Insumos

  • Datos del Banco Mundial (CSV)
  • Fuentes y huella del archivo

🏁 Ejemplo terminado (míralo después de intentarlo)

  • Notebook de ejemplo
  • Abrir el ejemplo en Colab

Antes de empezar

En Claude Code, con la carpeta del repositorio abierta, trabajarás en 03-datos/mi-trabajo/. Copia cada prompt con el botón Copiar, pégalo, lee lo que Claude propone y aprueba. Marca cada nivel al terminarlo.

📖 Detalles de la ruta: opciones de insumos, ética y la lección principal

¿Para quién es esta ruta?

Para quien trabaja (o quiere trabajar) con datos cuantitativos y quiere pasar de una pregunta a gráficas y un reporte que se puedan compartir y replicar, en Python, R o Stata.

Qué te llevas al final (≈35 min)

  • Un notebook (o script de R / do-file de Stata) que obtiene los datos, revisa qué falta, grafica y estima un modelo simple.
  • 3 gráficas listas para presentación, con fuente al pie.
  • Un reporte HTML sin código para mandar a colegas, y un Excel con los datos y las tablas usadas.

👉 Mira ejemplo-final/reporte_mexico_al.html para ver la meta.

El caso del kit: México en América Latina

¿Cómo ha evolucionado la violencia en México frente a la región, y se relaciona con la desigualdad o el ingreso? Usa datos reales del Banco Mundial (17 países, 2000–2023): homicidios, PIB per cápita, Gini y desempleo.

Dos caminos para los datos

Camino Qué haces
A · Descargar de la API Le pides a Claude Code que consulte la API pública del Banco Mundial (sin registro)
B · Copia del repositorio Usas datos/wdi_latam.csv (ver datos/FUENTES.md)

¿Tus propios datos?

Puedes traer un CSV o Excel de tu investigación (público o anonimizado) a 03-datos/mi-trabajo/ y usar los mismos prompts con tu pregunta. No uses datos confidenciales.

Python, R o Stata

Lenguaje Cómo funciona
Python Claude Code escribe y ejecuta el notebook; también puedes abrirlo en Colab
R Claude Code escribe y ejecuta un script .R o un documento Quarto, si tienes R instalado
Stata Claude Code escribe el .do; lo ejecuta si Stata está instalado y accesible desde la terminal. Si no, lo corres tú

Dónde trabajar

Abre en Claude Code la carpeta del repositorio y trabaja en 03-datos/mi-trabajo/.

Pasos

Abre prompts.md y sigue los niveles en orden.

La lección de esta ruta

Claude Code programa rápido, pero la interpretación es tuya. Al construir el ejemplo, la primera versión del texto final afirmaba algo que las gráficas contradecían. Revisar que cada frase del reporte coincida con los números es parte del método.

Copia y pega cada prompt en Claude Code (pestaña Code, con la carpeta del repositorio abierta). Si prefieres R o Stata, cambia "notebook de Python" por "script de R" o "do-file de Stata".

Preparar el terreno

2 min
Crea la carpeta 03-datos/mi-trabajo/ y trabaja ahí.
Revisa si tengo Python con pandas, matplotlib, statsmodels y jupyter
(o R, o Stata, según el lenguaje que elija). Dime qué falta; no instales nada todavía.

✅ Deberías ver

Claude te dice qué tienes instalado y qué falta, sin instalar nada.

Conseguir los datos Elige A o B

6 min

Opción A · API del Banco Mundial

Quiero comparar a México con América Latina en violencia, desigualdad e ingreso.
Usa la API pública del Banco Mundial (WDI) para descargar, de 2000 a 2023 y para
los 17 países latinoamericanos principales, estos indicadores:
homicidios por 100,000 habitantes, PIB per cápita PPA, índice de Gini y desempleo.
Si la API falla, reintenta. Guarda los datos en mi-trabajo/datos/ y anota en un
archivo FUENTES.md las URLs consultadas y la fecha.

Opción B · Copia del repositorio

Quiero comparar a México con América Latina en violencia, desigualdad e ingreso.
Usa los datos de 03-datos/datos/wdi_latam.csv. Lee primero 03-datos/datos/FUENTES.md
y verifica la huella SHA-256 del archivo. Explícame su estructura.

💡 Qué aprendes: Claude Code sabe usar APIs públicas (Banco Mundial, INEGI, OCDE) y documentar de dónde salió cada dato.

✅ Deberías ver

Los datos en tu carpeta y un FUENTES.md con URLs y fecha (opción A), o la huella del archivo verificada (opción B).

¿Qué falta?

5 min
Antes de graficar, crea un notebook de Python en mi-trabajo/ y haz una tabla de
cobertura: qué porcentaje de años tiene dato cada país en cada indicador.
Dime qué países o indicadores tienen huecos que podrían sesgar los promedios.

💡 Qué aprendes: revisar los datos faltantes antes de graficar evita conclusiones falsas.

✅ Deberías ver

Una tabla de cobertura con el % de años con dato por país e indicador.

Gráficas que cuentan algo

10 min
Agrega al notebook tres gráficas:
1. La tasa de homicidios de México frente a la mediana del resto de los países
   (los demás países en gris de fondo).
2. Homicidios en el último año disponible, país por país, con México resaltado.
3. Dispersión del Gini contra los homicidios (promedios 2015–2023), con la correlación
   de Spearman en el título.
Usa pocos colores (México en un solo color fuerte), títulos que digan el hallazgo,
y la fuente al pie de cada gráfica. Guárdalas como PNG.

Pide ajustes en lenguaje natural: "la etiqueta del eje se corta", "pon los nombres en español", "quita la cuadrícula vertical".

💡 Qué aprendes: un título que afirma algo se lee mejor que un título descriptivo. Pero entonces el título tiene que ser cierto.

✅ Deberías ver

Tres archivos PNG con fuente al pie y un título que afirma algo.

Un modelo y sus límites

6 min
Estima un modelo de panel con efectos fijos de país y de año: homicidios en función
de log(PIB per cápita), Gini y desempleo, con errores estándar agrupados por país.
Explícame el resultado en lenguaje llano y dime sus tres principales limitaciones.

💡 Qué aprendes: Claude Code puede estimar el modelo, pero la discusión de identificación te toca a ti.

✅ Deberías ver

Una tabla de coeficientes y una explicación en lenguaje llano con 3 limitaciones.

Revisar y compartir

6 min
Escribe una sección final "Lectura y límites" con 4 viñetas. Después, verifica cada
afirmación contra los números calculados en el notebook y muéstrame una tabla:
afirmación, número que la respalda, ¿coincide?
Al final, exporta un reporte HTML sin código para compartir.

💡 Qué aprendes: audita el texto contra los números. Al preparar el ejemplo, esta revisión encontró una afirmación sobre El Salvador que los datos contradecían.

✅ Deberías ver

Una tabla “afirmación – número – ¿coincide?” y un reporte HTML sin código.

Retos para quien termine antes

Contrasta la serie de homicidios de México del Banco Mundial con la de INEGI
(defunciones por homicidio). ¿Coinciden? ¿Por qué podrían diferir?

Traduce todo el análisis a un script de R con ggplot2 (o a un do-file de Stata).

Convierte las tres gráficas en una sola figura de paneles, lista para un artículo.

Reglas de oro

  1. Mira los datos faltantes antes que las gráficas.
  2. Un título que afirma, tiene que ser verdad. Verifícalo.
  3. Correlación no es causalidad, y un modelo con 17 países es exploratorio.
