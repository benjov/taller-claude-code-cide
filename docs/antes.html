Antes del taller

Lista de verificación: márcala conforme avanzas (se guarda en tu navegador)

Haz esto antes de llegar (10–15 minutos). Si llegas con todo listo, aprovechas los 60 minutos completos.

⚠️ Requisito indispensable

Claude Code requiere un plan de pago de Claude: Pro, Max, Ultra, Team o Enterprise. El plan gratuito no incluye Claude Code. Si tu institución te dio una cuenta, verifica con ella que incluya Claude Code.

  1. Descárgala de claude.com/download (macOS o Windows) e inicia sesión con tu cuenta.

  2. En la app verás la pestaña Code. Ahí trabajaremos todo el taller (no en el chat normal).

  3. Elige una forma:

    • Sin saber Git (recomendado): ⬇ Descargar ZIP y descomprímelo en tu carpeta Documentos.
    • Con Claude Code: en la pestaña Code, abre cualquier carpeta y pega: 
      Clona el repositorio https://github.com/benjov/taller-claude-code-cide en mi carpeta Documentos
    • Con Git: git clone https://github.com/benjov/taller-claude-code-cide.git

  4. En la pestaña Code, debajo del cuadro de texto, está el selector de carpeta. Elige la carpeta taller-claude-code-cide (o taller-claude-code-cide-main si la descargaste como ZIP).

  5. Pega este prompt y envíalo:

    Hola. Lee el README.md de esta carpeta y dime en 3 líneas de qué trata este taller y qué rutas hay.

    ✅ Si te responde con un resumen del taller y la lista de rutas, estás lista o listo.

  6. Pega este prompt:

    ¿Tengo Python 3 instalado con pandas, matplotlib, requests, openpyxl y jupyter? Dímelo sin instalar nada.

    Si falta algo, no te preocupes: en el taller se lo pedimos a Claude Code o usamos Google Colab (solo necesitas una cuenta de Google).

¿No tienes la app de escritorio?

Puedes usar Claude Code en la web (claude.ai/code). Corre en la nube de Anthropic y trabaja sobre repositorios de GitHub:

  1. Necesitas una cuenta de GitHub y conectarla a Claude cuando te lo pida.
  2. El repositorio del taller es público. Lo más sencillo es hacer un fork (copia en tu cuenta) desde la página del repo con el botón Fork, y abrir la sesión sobre tu copia.
  3. Los archivos que cree Claude quedan en la nube; pídele que los guarde en tu fork para verlos y descargarlos desde GitHub.

Recomendación

Para este taller la app de escritorio es más sencilla: trabajas con archivos de tu computadora y ves los resultados al instante.
