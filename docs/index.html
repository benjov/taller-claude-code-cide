Claude Code para investigación en ciencias sociales

Taller práctico · 60 minutos · cada participante sale con un producto terminado

En 60 minutos vas a usar Claude Code para terminar un producto real para tu trabajo académico: una página web, el sitio de un curso, un análisis de datos, una revisión de literatura, una codificación cualitativa o un análisis auditable con datos oficiales.

1Antes del tallerInstala, descarga el repo y haz la prueba (10 min) 2Primeros pasosAbre Claude Code y conoce lo básico 3Elige tu rutaY síguela nivel por nivel

Agenda de la sesión

  1. 00–05′
    Bienvenida y demo

    La persona que facilita muestra, en vivo, un CV convertido en página web en 3 minutos.

  2. 05–15′
    Primeros pasos

    Todas y todos abren Claude Code, eligen la carpeta del taller, conocen los permisos y eligen ruta.

  3. 15–50′
    Trabajo por rutas

    Cada quien avanza por los niveles de su ruta. Ayudantes recorren el salón.

  4. 50–57′
    Galería

    3 o 4 voluntarios muestran su producto en pantalla (1–2 minutos cada uno).

  5. 57–60′
    Cierre

    Reglas de oro y cómo seguir usando Claude Code en tu trabajo.

¿Vas a facilitar? Abre el reloj de la sesión en el proyector.

Las seis rutas

🌐01 · Web académicaTu página web académica personal (un solo archivo HTML), creada desde tu CV.📅02 · SyllabusSitio del curso con fechas reales, lecturas y entregas, más un calendario .ics para tus estudiantes.📊03 · DatosNotebook reproducible con datos del Banco Mundial, 3 gráficas, un modelo simple y un reporte HTML.📚04 · LiteraturaMatriz de revisión con citas a página, alertas de lectura crítica y referencias verificadas en Crossref.🗣️05 · CualitativoAnonimización, libro de códigos, matriz de codificación con citas verificadas e informe de hallazgos.🔎06 · Fuentes auditablesNotebook que obtiene microdatos de INEGI, replica la tasa de informalidad y la valida contra lo publicado.

Qué es (y qué no es) Claude Code

Es…

  • Un agente: lee tus archivos, escribe archivos nuevos y ejecuta programas en una carpeta de tu computadora (o en la nube).
  • Un asistente al que le das tareas completas en lenguaje natural: “lee este PDF, haz una tabla, verifícala”.
  • Algo que te pide permiso antes de editar o ejecutar, según el modo que elijas.

No es…

  • Un chat donde copias y pegas: aquí trabaja directamente sobre tus archivos.
  • Infalible: puede equivocarse o “embellecer”. Por eso cada ruta incluye un nivel de verificación.
  • Un sustituto de tu criterio académico: tú decides y tú firmas.
